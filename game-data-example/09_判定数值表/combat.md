## 基础属性

| 属性 | 说明 | 初始值 | 成长方式 |
|------|------|--------|----------|
| HP | 生命值 | 100 | 装备/药水/休息 |
| MP | 魔力值 | 50 | 装备/药水/冥想 |
| ATK | 攻击力 | 5 | 武器/技能/训练 |
| DEF | 防御力 | 3 | 装备/技能/训练 |

## 战斗判定规则

### 攻击判定
- 基础伤害 = ATK + 随机(1~6)

### 防御判定
- 受伤 = 敌 ATK + 随机(1~6) - DEF
